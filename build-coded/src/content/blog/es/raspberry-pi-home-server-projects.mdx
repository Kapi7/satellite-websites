**CUERPO TRADUCIDO:**

La Raspberry Pi ha sido desde hace mucho tiempo la consentida de la comunidad DIY de tecnología, una computadora pequeñita y accesible que puede dar golpes mucho más fuertes de lo que aparenta. Mientras miramos hacia el 2026, el panorama para los entusiastas de los servidores caseros está más brillante que nunca, gracias en gran parte a la llegada de la Raspberry Pi 5. Con su rendimiento significativamente mejorado, I/O más rápido y una gestión térmica superior, la Pi 5 transforma lo que antes era un experimento divertido en una plataforma genuinamente robusta para servicios caseros esenciales.

Para cualquiera de los proyectos que discutimos aquí, te recomendamos encarecidamente la **Raspberry Pi 5 con 8GB de RAM**. Este modelo ofrece memoria de sobra para aplicaciones demandantes, multitarea y para asegurar que tu configuración esté lista para el futuro. Su potente procesador quad-core ARM Cortex-A76 ofrece un rendimiento de nivel de escritorio, mientras que la interfaz PCI-E 2.0 dedicada desbloquea el potencial de un almacenamiento NVMe SSD súper rápido, ¡un verdadero cambio de juego para aplicaciones de servidor! Combina esto con Gigabit Ethernet, doble salida de video 4K y Wi-Fi 6, y tendrás una base increíblemente capaz.

Configurar un servidor casero no se trata solo de ahorrar dinero; se trata de recuperar el control de tus datos, mejorar tu privacidad y personalizar tu entorno digital exactamente como lo quieres. Ya sea que estés harto de anuncios intrusivos, quieras centralizar tu contenido multimedia o construir la casa inteligente definitiva, la Raspberry Pi 5 hace que estas ambiciones no solo sean posibles, sino prácticas y disfrutables.

Antes de que te lances de lleno, un consejo crucial: aunque la Raspberry Pi 5 es potente, **no intentes ejecutar los ocho proyectos en una sola Pi**. La contención de recursos, especialmente para I/O y CPU, te llevará a una experiencia frustrante. En su lugar, elige uno o dos proyectos principales que se alineen con tus necesidades inmediatas, o considera dedicar Pis separadas para tareas particularmente intensivas en recursos, como un servidor multimedia o un NAS.

Aquí tienes ocho proyectos de servidor casero con Raspberry Pi que valen absolutamente la pena construir en 2026, aprovechando todo el potencial de la Raspberry Pi 5.

### 1. Pi-hole: Bloqueo de Anuncios a Nivel de Red

**Qué hace:** Pi-hole actúa como un "sumidero DNS", bloqueando anuncios y dominios maliciosos para todos los dispositivos de tu red sin necesidad de extensiones individuales en el navegador. Cuando un dispositivo solicita un dominio, Pi-hole verifica si está en una lista de bloqueo. Si lo está, Pi-hole devuelve una dirección "inexistente", impidiendo que el anuncio o rastreador se cargue. Funciona a nivel de red, lo que significa que los anuncios se bloquean en apps, smart TVs y dispositivos IoT, no solo en navegadores web.

**Por qué vale la pena construirlo:** En 2026, la publicidad en línea sigue siendo omnipresente y cada vez más agresiva. Pi-hole ofrece una solución potente y a nivel de sistema para combatirla. Mejora significativamente el rendimiento de la red al evitar que el contenido publicitario se descargue siquiera, aumenta la privacidad bloqueando dominios de rastreo y proporciona una experiencia de navegación más limpia y rápida para todos en casa. Es increíblemente satisfactorio ver las estadísticas en tiempo real de cuántos anuncios y rastreadores se han bloqueado. La gran cantidad de RAM y la red rápida de la Pi 5 aseguran que Pi-hole funcione sin ninguna latencia perceptible.

**Hardware necesario además de la Pi:**
*   Tarjeta microSD de alta resistencia (se recomiendan 16GB+ para el sistema operativo) O un SSD NVMe (con un HAT M.2 adecuado para la Pi 5) para el sistema operativo. El NVMe es muy recomendable para longevidad y velocidad.
*   Fuente de alimentación oficial Raspberry Pi 5 (USB-C de 27W).
*   Cable Ethernet (para una estabilidad óptima de la red, aunque el Wi-Fi 6 funciona).

**Método de instalación (Docker Compose):**
Docker es una excelente manera de ejecutar Pi-hole, aislándolo de tu sistema operativo principal y simplificando las actualizaciones.

```yaml
version: "3"

services:
  pihole:
    container_name: pihole
    image: pihole/pihole:latest
    ports:
      - "53:53/tcp"
      - "53:53/udp"
      - "67:67/udp" # Solo se requiere si estás usando Pi-hole como tu servidor DHCP
      - "80:80/tcp"
    environment:
      TZ: 'America/New_Creek' # Reemplaza con tu zona horaria
      WEBPASSWORD: 'tu_contraseña_segura_de_administrador' # ¡Cambia esto!
      FTLCONF_REPLY_ADDR4: '192.168.1.10' # Reemplaza con la dirección IP estática de tu Pi
    volumes:
      - './etc-pihole:/etc/pihole'
      - './etc-dnsmasq.d:/etc/dnsmasq.d'
    # Recomendado para Pi-hole, o no se reiniciará después de un reinicio
    cap_add:
      - NET_ADMIN
    restart: unless-stopped
```
Después de guardar esto como `docker-compose.yml`, navega al directorio en tu terminal y ejecuta `docker compose up -d`. Luego configura tu router o dispositivos para que usen la dirección IP de tu Pi como su servidor DNS.

**Carga de mantenimiento:** Baja. Una vez configurado, Pi-hole se ejecuta prácticamente solo. Las tareas principales son actualizaciones ocasionales (a través de `docker compose pull` y `docker compose up -d`) y agregar/eliminar listas de bloqueo.

**¿Quién no debería molestarse?** Personas que dependen mucho de sitios web o servicios específicos que se rompen sin anuncios (aunque Pi-hole ofrece una lista blanca fácil de usar), o aquellos que prefieren bloqueadores de anuncios del lado del cliente para funciones específicas del navegador. Si no te molestan los anuncios en absoluto, este proyecto no te ofrecerá mucho beneficio.

### 2. Home Assistant: El Cerebro Definitivo de la Casa Inteligente

**Qué hace:** Home Assistant (HA) es una plataforma de automatización del hogar de código abierto que prioriza el control local y la privacidad. Se integra con miles de dispositivos inteligentes, servicios y plataformas, permitiéndote crear automatizaciones complejas, paneles y scripts que unen toda tu tecnología de casa inteligente bajo un mismo techo, a menudo sin depender de servicios en la nube. Desde luces y termostatos hasta sensores y reproductores multimedia, HA puede controlar casi todo.

**Por qué vale la pena construirlo:** A medida que las casas inteligentes se vuelven más comunes en 2026, crece la necesidad de un sistema de control centralizado, privado y flexible. Home Assistant te libera del encierro de los proveedores, las aplicaciones fragmentadas y las preocupaciones de privacidad asociadas con los sistemas dependientes de la nube. La potencia de procesamiento y los 8GB de RAM de la Pi 5 son perfectos para manejar una gran cantidad de integraciones, procesar automatizaciones complejas y servir una interfaz web receptiva. Permite una personalización sin precedentes, dándote control total sobre la inteligencia de tu hogar.

**Hardware necesario además de la Pi:**
*   Se recomienda encarecidamente un SSD NVMe (con HAT M.2) para el sistema operativo y la base de datos de HA, ya que las tarjetas SD pueden desgastarse rápidamente con escrituras frecuentes.
*   Fuente de alimentación oficial Raspberry Pi 5.
*   Dongle USB Zigbee/Z-Wave (por ejemplo, Sonoff Zigbee 3.0 USB Dongle Plus, Aeotec Z-Stick) si planeas integrar dispositivos Zigbee o Z-Wave.
*   Cable Ethernet (recomendado para estabilidad).
*   Opcional: UPS (Sistema de Alimentación Ininterrumpida) para protección contra cortes de energía.

**Método de instalación (Docker Compose - Contenedor de Home Assistant):**
Este método ejecuta Home Assistant como un contenedor Docker en una instalación estándar de Raspberry Pi OS.

```yaml
version: '3'
services:
  homeassistant:
    container_name: homeassistant
    image: ghcr.io/home-assistant/home-assistant:stable
    volumes:
      - ./config:/config
      - /etc/localtime:/etc/localtime:ro
    restart: unless-stopped
    privileged: true # Requerido para algunos dispositivos USB como dongles Zigbee/Z-Wave
    network_mode: host # Permite que HA descubra dispositivos en tu red
    environment:
      TZ: 'America/New_Creek' # Reemplaza con tu zona horaria
```
Guarda esto como `docker-compose.yml`, crea un directorio `config` en la misma ubicación (`mkdir config`), luego ejecuta `docker compose up -d`. Home Assistant será accesible en `http://tu_ip_de_la_pi:8123`.

**Carga de mantenimiento:** Alta. Si bien el sistema principal es estable, Home Assistant evoluciona rápidamente con actualizaciones mensuales, nuevas funciones y cambios que rompen la compatibilidad. Mantener las integraciones funcionando, solucionar problemas y refinar constantemente las automatizaciones requiere dedicación y voluntad de aprender. Es un pasatiempo continuo, no una solución de "configurar y olvidar".

**¿Quién no debería molestarse?** Usuarios que prefieren dispositivos de casa inteligente simples y plug-and-play con configuración mínima, o aquellos que no se sienten cómodos solucionando problemas, leyendo documentación e invirtiendo tiempo en la personalización. Si solo quieres encender una luz con la voz y no te importa el control local ni las automatizaciones avanzadas, un hub comercial podría ser una mejor opción.

### 3. Plex / Jellyfin Media Server: Tu Netflix Personal

**Qué hace:** Un servidor multimedia te permite centralizar tu colección personal de películas, series, música y fotos, haciéndola accesible desde cualquier dispositivo en tu hogar (y potencialmente de forma remota). Plex es una opción popular y fácil de usar con una interfaz pulida y amplio soporte de clientes, aunque algunas funciones avanzadas son de pago. Jellyfin es una alternativa completamente gratuita y de código abierto que ofrece una funcionalidad similar sin restricciones propietarias.

**Por qué vale la pena construirlo:** A medida que los servicios de streaming se fragmentan y el contenido se vuelve más difícil de encontrar en diferentes plataformas, un servidor multimedia personal se vuelve invaluable. Ofrece una experiencia dedicada y sin anuncios para tu propio contenido, asegura que siempre tengas acceso a tu biblioteca independientemente de la conexión a Internet y te permite compartir medios con familiares y amigos. La Pi 5, con su CPU mejorada y almacenamiento PCIe, puede manejar cómodamente múltiples transmisiones simultáneas transcodificadas, especialmente para contenido 1080p, convirtiéndola en una alternativa viable a hardware dedicado más caro. Jellyfin, al ser de código abierto, te da control total y privacidad.

**Hardware necesario además de la Pi:**
*   Discos duros externos USB 3.0 grandes (HDD o SSD) para almacenar tus medios. Considera una carcasa para múltiples discos si tu colección es extensa.
*   SSD NVMe (con HAT M.2) para el sistema operativo y la aplicación, asegurando una interfaz de usuario y un rendimiento de base de datos receptivos.
*   Fuente de alimentación oficial Raspberry Pi 5.
*   Cable Ethernet (absolutamente esencial para una transmisión de medios confiable).

**Método de instalación (Docker Compose para Jellyfin):**
Nos centraremos en Jellyfin por su naturaleza de código abierto y su excelente rendimiento en la Pi.

```yaml
version: "3.8"
services:
  jellyfin:
    image: jellyfin/jellyfin:latest
    container_name: jellyfin
    user: 1000:1000 # Reemplaza con tu ID de usuario y ID de grupo (ej. `id -u` y `id -g` en terminal)
    network_mode: host # Simplifica la configuración de red para el descubrimiento
    volumes:
      - ./config:/config # Archivos de configuración
      - ./cache:/cache   # Directorio de caché
      - /ruta/a/tus/medios:/media:ro # Monta tu biblioteca de medios, reemplaza con la ruta real
      # - /ruta/a/tus/series:/tvshows:ro # Opcional: montajes separados para organización
      # - /ruta/a/tus/peliculas:/movies:ro # Opcional: montajes separados para organización
    restart: unless-stopped
    environment:
      TZ: 'America/New_Creek' # Reemplaza con tu zona horaria
      PUID: 1000 # ID de usuario - coincide con 'user' arriba
      PGID: 1000 # ID de grupo - coincide con 'user' arriba
    # Para transcodificación por hardware en Raspberry Pi 5 (requiere configuración específica en la UI de Jellyfin)
    # devices:
    #   - /dev/dri/renderD128:/dev/dri/renderD128
```
Guarda como `docker-compose.yml`, crea los directorios `config` y `cache`, asegúrate de que tu directorio de medios sea accesible, y luego ejecuta `docker compose up -d`. Jellyfin estará en `http://tu_ip_de_la_pi:8096`. Nota: El soporte de transcodificación por hardware para la VPU de la Pi 5 en Docker puede requerir configuración adicional y módulos del kernel, pero la transcodificación por software es robusta en la CPU de la Pi 5 para la mayoría del contenido 1080p.

**Carga de mantenimiento:** Media. La configuración inicial requiere organizar tus medios y configurar bibliotecas. Las tareas continuas incluyen agregar nuevos medios, actualizar Jellyfin (a través de `docker compose pull` y `docker compose up -d`) y asegurarse de que tus discos externos estén en buen estado.

**¿Quién no debería molestarse?** Personas que usan exclusivamente servicios de streaming comerciales y no tienen interés en curar su propia biblioteca de medios. Si estás contento con Netflix, Disney+, etc., y no posees copias digitales de medios, este proyecto no es para ti.
