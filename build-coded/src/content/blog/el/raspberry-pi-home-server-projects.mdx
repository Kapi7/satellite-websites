Το Raspberry Pi είναι εδώ και καιρό το αγαπημένο παιχνίδι της DIY tech κοινότητας, ένας μικρός, οικονομικός υπολογιστής που μπορεί να κάνει θαύματα. Κοιτώντας μπροστά στο 2026, το σκηνικό για τους λάτρεις των home servers είναι πιο λαμπερό από ποτέ, χάρη και στην άφιξη του Raspberry Pi 5. Με την αισθητά βελτιωμένη του απόδοση, το ταχύτερο I/O και την καλύτερη διαχείριση θερμότητας, το Pi 5 μετατρέπει αυτό που κάποτε ήταν ένα διασκεδαστικό πείραμα σε μια πραγματικά στιβαρή πλατφόρμα για βασικές οικιακές υπηρεσίες.

Για οποιοδήποτε από τα project που συζητάμε εδώ, προτείνουμε ανεπιφύλακτα το **Raspberry Pi 5 με 8GB RAM**. Αυτό το μοντέλο προσφέρει άφθονη μνήμη για απαιτητικές εφαρμογές, multitasking και future-proofing του setup σου. Ο πανίσχυρος τετραπύρηνος επεξεργαστής ARM Cortex-A76 του προσφέρει απόδοση επιπέδου desktop, ενώ η αποκλειστική διεπαφή PCI-E 2.0 ξεκλειδώνει τη δυνατότητα για αστραπιαία NVMe SSD αποθήκευση – ένα game-changer για εφαρμογές server. Συνδύασε το με Gigabit Ethernet, διπλή έξοδο οθόνης 4K και Wi-Fi 6, και έχεις μια απίστευτα ικανή βάση.

Η δημιουργία ενός home server δεν είναι μόνο για να γλιτώσεις χρήματα. Είναι για να ανακτήσεις τον έλεγχο των δεδομένων σου, να βελτιώσεις την ιδιωτικότητα και να προσαρμόσεις το ψηφιακό σου περιβάλλον ακριβώς όπως το θέλεις. Είτε έχεις βαρεθεί τις ενοχλητικές διαφημίσεις, είτε θέλεις να συγκεντρώσεις τα media σου, είτε θέλεις να φτιάξεις το απόλυτο smart home, το Raspberry Pi 5 κάνει αυτές τις φιλοδοξίες όχι μόνο εφικτές, αλλά πρακτικές και ευχάριστες.

Πριν βουτήξεις, μια κρίσιμη συμβουλή: παρόλο που το Raspberry Pi 5 είναι πανίσχυρο, **μην προσπαθήσεις να τρέξεις και τα οκτώ αυτά project σε ένα μόνο Pi**. Ο ανταγωνισμός πόρων, ειδικά για I/O και CPU, θα οδηγήσει σε μια απογοητευτική εμπειρία. Αντίθετα, επίλεξε ένα ή δύο βασικά project που ταιριάζουν στις άμεσες ανάγκες σου, ή σκέψου να αφιερώσεις ξεχωριστά Pis για ιδιαίτερα απαιτητικές εργασίες όπως ένας media server ή NAS.

Εδώ είναι οκτώ projects home server με Raspberry Pi που αξίζει απόλυτα να φτιάξεις το 2026, αξιοποιώντας πλήρως τις δυνατότητες του Raspberry Pi 5.

### 1. Pi-hole: Ad Blocking σε Όλο το Δίκτυο

**Τι κάνει:** Το Pi-hole λειτουργεί ως DNS sinkhole, μπλοκάροντας διαφημίσεις και κακόβουλα domains για κάθε συσκευή στο δίκτυό σου, χωρίς να χρειάζεται ξεχωριστά browser extensions. Όταν μια συσκευή ζητάει ένα domain, το Pi-hole ελέγχει αν είναι σε λίστα μπλοκαρίσματος. Αν είναι, το Pi-hole επιστρέφει μια "μη υπαρκτή" διεύθυνση, εμποδίζοντας τη φόρτωση της διαφήμισης ή του tracker. Λειτουργεί σε επίπεδο δικτύου, που σημαίνει ότι οι διαφημίσεις μπλοκάρονται σε apps, smart TVs και IoT συσκευές, όχι μόνο σε web browsers.

**Γιατί αξίζει να το φτιάξεις:** Το 2026, η online διαφήμιση συνεχίζει να είναι πανταχού παρούσα και όλο και πιο επιθετική. Το Pi-hole προσφέρει μια ισχυρή, συστημική λύση για να την αντιμετωπίσεις. Βελτιώνει σημαντικά την απόδοση του δικτύου εμποδίζοντας ακόμη και τη λήψη περιεχομένου διαφημίσεων, ενισχύει την ιδιωτικότητα μπλοκάροντας domains παρακολούθησης και προσφέρει μια πιο καθαρή, ταχύτερη εμπειρία περιήγησης για όλους στο σπίτι. Είναι απίστευτα ικανοποιητικό να βλέπεις τα στατιστικά σε πραγματικό χρόνο για το πόσες διαφημίσεις και trackers έχουν μπλοκαριστεί. Η άφθονη RAM και η γρήγορη δικτύωση του Pi 5 εξασφαλίζουν ότι το Pi-hole τρέχει χωρίς καμία αισθητή καθυστέρηση.

**Hardware που χρειάζεσαι εκτός Pi:**
*   microSD κάρτα υψηλής αντοχής (16GB+ προτείνεται για το OS) Ή NVMe SSD (με κατάλληλο M.2 HAT για το Pi 5) για το OS. Το NVMe συνιστάται ανεπιφύλακτα για μακροζωία και ταχύτητα.
*   Επίσημο τροφοδοτικό Raspberry Pi 5 (27W USB-C).
*   Καλώδιο Ethernet (για βέλτιστη σταθερότητα δικτύου, αν και το Wi-Fi 6 δουλεύει).

**Μέθοδος εγκατάστασης (Docker Compose):**
Το Docker είναι ένας εξαιρετικός τρόπος για να τρέξεις το Pi-hole, απομονώνοντάς το από το κύριο OS σου και κάνοντας τις αναβαθμίσεις απλές.

```yaml
version: "3"

services:
  pihole:
    container_name: pihole
    image: pihole/pihole:latest
    ports:
      - "53:53/tcp"
      - "53:53/udp"
      - "67:67/udp" # Απαιτείται μόνο αν χρησιμοποιείς το Pi-hole ως DHCP server
      - "80:80/tcp"
    environment:
      TZ: 'America/New_Creek' # Άλλαξε με τη δική σου ζώνη ώρας
      WEBPASSWORD: 'your_secure_admin_password' # Άλλαξέ το αυτό!
      FTLCONF_REPLY_ADDR4: '192.168.1.10' # Άλλαξε με τη στατική IP του Pi σου
    volumes:
      - './etc-pihole:/etc/pihole'
      - './etc-dnsmasq.d:/etc/dnsmasq.d'
    # Προτείνεται για το Pi-hole, αλλιώς δεν θα επανεκκινήσει μετά από reboot
    cap_add:
      - NET_ADMIN
    restart: unless-stopped
```
Αφού αποθηκεύσεις αυτό ως `docker-compose.yml`, πήγαινε στον φάκελο στο τερματικό σου και τρέξε `docker compose up -d`. Στη συνέχεια, ρύθμισε το router σου ή τις συσκευές σου να χρησιμοποιούν την IP του Pi σου ως DNS server.

**Επιβάρυνση συντήρησης:** Χαμηλή. Μόλις στηθεί, το Pi-hole τρέχει σχεδόν από μόνο του. Περιοδικές αναβαθμίσεις (μέσω `docker compose pull` και `docker compose up -d`) και η προσθήκη/αφαίρεση λιστών μπλοκαρίσματος είναι οι κύριες εργασίες.

**Ποιοι δεν πρέπει να ασχοληθούν:** Άτομα που βασίζονται πολύ σε συγκεκριμένες ιστοσελίδες ή υπηρεσίες που "σπάνε" χωρίς διαφημίσεις (αν και το Pi-hole προσφέρει εύκολο whitelisting), ή όσοι προτιμούν ad blockers από την πλευρά του client για συγκεκριμένα χαρακτηριστικά του browser. Αν δεν σε πειράζουν καθόλου οι διαφημίσεις, αυτό το project δεν θα σου προσφέρει πολλά οφέλη.

### 2. Home Assistant: Ο Απόλυτος Εγκέφαλος του Smart Home

**Τι κάνει:** Το Home Assistant (HA) είναι μια open-source πλατφόρμα αυτοματισμού σπιτιού που δίνει προτεραιότητα στον τοπικό έλεγχο και την ιδιωτικότητα. Ενσωματώνεται με χιλιάδες smart συσκευές, υπηρεσίες και πλατφόρμες, επιτρέποντάς σου να δημιουργείς πολύπλοκους αυτοματισμούς, dashboards και scripts που φέρνουν όλη την τεχνολογία του smart home σου κάτω από την ίδια στέγη, συχνά χωρίς να βασίζεσαι σε cloud υπηρεσίες. Από φωτισμό και θερμοστάτες μέχρι αισθητήρες και media players, το HA μπορεί να ελέγξει σχεδόν τα πάντα.

**Γιατί αξίζει να το φτιάξεις:** Καθώς τα smart homes γίνονται όλο και πιο διαδεδομένα το 2026, η ανάγκη για ένα κεντρικό, ιδιωτικό και ευέλικτο σύστημα ελέγχου αυξάνεται. Το Home Assistant σε απελευθερώνει από το vendor lock-in, τις κατακερματισμένες εφαρμογές και τις ανησυχίες για την ιδιωτικότητα που σχετίζονται με συστήματα που βασίζονται στο cloud. Η επεξεργαστική ισχύς και τα 8GB RAM του Pi 5 είναι ιδανικά για να διαχειριστούν μεγάλο αριθμό ενσωματώσεων, να επεξεργαστούν πολύπλοκους αυτοματισμούς και να εξυπηρετήσουν ένα responsive web interface. Επιτρέπει απαράμιλλη προσαρμογή, δίνοντάς σου πλήρη έλεγχο στην "ευφυΐα" του σπιτιού σου.

**Hardware που χρειάζεσαι εκτός Pi:**
*   NVMe SSD (με M.2 HAT) συνιστάται ανεπιφύλακτα για το OS και τη βάση δεδομένων του HA, καθώς οι SD κάρτες φθείρονται γρήγορα με συχνές εγγραφές.
*   Επίσημο τροφοδοτικό Raspberry Pi 5.
*   Zigbee/Z-Wave USB dongle (π.χ., Sonoff Zigbee 3.0 USB Dongle Plus, Aeotec Z-Stick) αν σκοπεύεις να ενσωματώσεις Zigbee ή Z-Wave συσκευές.
*   Καλώδιο Ethernet (συνιστάται για σταθερότητα).
*   Προαιρετικά: UPS (Uninterruptible Power Supply) για προστασία από διακοπές ρεύματος.

**Μέθοδος εγκατάστασης (Docker Compose - Home Assistant Container):**
Αυτή η μέθοδος τρέχει το Home Assistant ως Docker container σε μια τυπική εγκατάσταση Raspberry Pi OS.

```yaml
version: '3'
services:
  homeassistant:
    container_name: homeassistant
    image: ghcr.io/home-assistant/home-assistant:stable
    volumes:
      - ./config:/config
      - /etc/localtime:/etc/localtime:ro
    restart: unless-stopped
    privileged: true # Απαιτείται για ορισμένα USB devices όπως Zigbee/Z-Wave dongles
    network_mode: host # Επιτρέπει στο HA να ανακαλύψει συσκευές στο δίκτυό σου
    environment:
      TZ: 'America/New_Creek' # Άλλαξε με τη δική σου ζώνη ώρας
```
Αποθήκευσε αυτό ως `docker-compose.yml`, δημιούργησε έναν φάκελο `config` στην ίδια τοποθεσία (`mkdir config`), και μετά τρέξε `docker compose up -d`. Το Home Assistant θα είναι προσβάσιμο στη διεύθυνση `http://your_pi_ip:8123`.

**Επιβάρυνση συντήρησης:** Υψηλή. Ενώ το βασικό σύστημα είναι σταθερό, το Home Assistant εξελίσσεται ραγδαία με μηνιαίες αναβαθμίσεις, νέα χαρακτηριστικά και breaking changes. Το να διατηρείς τις ενσωματώσεις σου λειτουργικές, να λύνεις προβλήματα και να βελτιώνεις συνεχώς τους αυτοματισμούς απαιτεί αφοσίωση και προθυμία για μάθηση. Είναι ένα συνεχές χόμπι, όχι μια λύση "βάλε και ξέχασε".

**Ποιοι δεν πρέπει να ασχοληθούν:** Χρήστες που προτιμούν απλές, plug-and-play smart home συσκευές με ελάχιστο setup, ή όσοι δεν αισθάνονται άνετα με την επίλυση προβλημάτων, την ανάγνωση τεκμηρίωσης και την επένδυση χρόνου στην προσαρμογή. Αν απλά θες να ανάβεις ένα φως με τη φωνή σου και δεν σε νοιάζει ο τοπικός έλεγχος ή οι προηγμένοι αυτοματισμοί, ένας εμπορικός hub μπορεί να είναι καλύτερη επιλογή.

### 3. Plex / Jellyfin Media Server: Το Προσωπικό σου Netflix

**Τι κάνει:** Ένας media server σου επιτρέπει να συγκεντρώσεις την προσωπική σου συλλογή ταινιών, σειρών, μουσικής και φωτογραφιών, κάνοντάς την προσβάσιμη από οποιαδήποτε συσκευή στο σπίτι σου (και πιθανώς από απόσταση). Το Plex είναι μια δημοφιλής, φιλική προς τον χρήστη επιλογή με ένα κομψό interface και ευρεία υποστήριξη client, αν και ορισμένα προηγμένα χαρακτηριστικά είναι επί πληρωμή. Το Jellyfin είναι μια εντελώς δωρεάν και open-source εναλλακτική που προσφέρει παρόμοια λειτουργικότητα χωρίς κανέναν ιδιόκτητο περιορισμό.

**Γιατί αξίζει να το φτιάξεις:** Καθώς οι streaming υπηρεσίες κατακερματίζονται και το περιεχόμενο γίνεται όλο και πιο δύσκολο να βρεθεί σε διαφορετικές πλατφόρμες, ένας προσωπικός media server γίνεται ανεκτίμητος. Προσφέρει μια αποκλειστική, χωρίς διαφημίσεις εμπειρία για το δικό σου περιεχόμενο, διασφαλίζει ότι έχεις πάντα πρόσβαση στη βιβλιοθήκη σου ανεξάρτητα από τη σύνδεση στο internet, και σου επιτρέπει να μοιράζεσαι media με οικογένεια και φίλους. Το Pi 5, με τον βελτιωμένο του CPU και την PCIe αποθήκευση, μπορεί άνετα να διαχειριστεί πολλαπλά ταυτόχρονα transcoded streams, ειδικά για περιεχόμενο 1080p, καθιστώντας το μια βιώσιμη εναλλακτική σε πιο ακριβό εξοπλισμό. Το Jellyfin, όντας open source, σου δίνει πλήρη έλεγχο και ιδιωτικότητα.

**Hardware που χρειάζεσαι εκτός Pi:**
*   Μεγάλος εξωτερικός USB 3.0 σκληρός δίσκος (HDD ή SSD) για αποθήκευση media. Σκέψου ένα enclosure για πολλαπλούς δίσκους αν η συλλογή σου είναι εκτενής.
*   NVMe SSD (με M.2 HAT) για το OS και την εφαρμογή, εξασφαλίζοντας responsive UI και απόδοση βάσης δεδομένων.
*   Επίσημο τροφοδοτικό Raspberry Pi 5.
*   Καλώδιο Ethernet (απαραίτητο για αξιόπιστο streaming media).

**Μέθοδος εγκατάστασης (Docker Compose για Jellyfin):**
Θα εστιάσουμε στο Jellyfin για τη φύση του ως open source και την εξαιρετική του απόδοση στο Pi.

```yaml
version: "3.8"
services:
  jellyfin:
    image: jellyfin/jellyfin:latest
    container_name: jellyfin
    user: 1000:1000 # Άλλαξε με το δικό σου user ID και group ID (π.χ., `id -u` και `id -g` στο τερματικό)
    network_mode: host # Απλοποιεί το setup δικτύου για ανακάλυψη
    volumes:
      - ./config:/config # Αρχεία ρυθμίσεων
      - ./cache:/cache   # Φάκελος cache
      - /path/to/your/media:/media:ro # Σύνδεσε τη βιβλιοθήκη media σου, άλλαξε με την πραγματική διαδρομή
      # - /path/to/your/tvshows:/tvshows:ro # Προαιρετικό: ξεχωριστές συνδέσεις για οργάνωση
      # - /path/to/your/movies:/movies:ro # Προαιρετικό: ξεχωριστές συνδέσεις για οργάνωση
    restart: unless-stopped
    environment:
      TZ: 'America/New_Creek' # Άλλαξε με τη δική σου ζώνη ώρας
      PUID: 1000 # User ID - ταιριάζει με το 'user' παραπάνω
      PGID: 1000 # Group ID - ταιριάζει με το 'user' παραπάνω
    # Για hardware transcoding στο Raspberry Pi 5 (απαιτεί ειδικό setup στο Jellyfin UI)
    # devices:
    #   - /dev/dri/renderD128:/dev/dri/renderD128
```
Αποθήκευσε ως `docker-compose.yml`, δημιούργησε τους φακέλους `config` και `cache`, βεβαιώσου ότι ο φάκελος media σου είναι προσβάσιμος, και μετά τρέξε `docker compose up -d`. Το Jellyfin θα είναι διαθέσιμο στη διεύθυνση `http://your_pi_ip:8096`. Σημείωση: Η υποστήριξη hardware transcoding για το VPU του Pi 5 σε Docker μπορεί να απαιτεί επιπλέον ρυθμίσεις και kernel modules, αλλά το software transcoding είναι στιβαρό στην CPU του Pi 5 για το μεγαλύτερο μέρος του περιεχομένου 1080p.

**Επιβάρυνση συντήρησης:** Μέτρια. Το αρχικό setup απαιτεί οργάνωση των media σου και ρύθμιση βιβλιοθηκών. Οι συνεχείς εργασίες περιλαμβάνουν την προσθήκη νέων media, την αναβάθμιση του Jellyfin (μέσω `docker compose pull` και `docker compose up -d`) και τη διασφάλιση ότι οι εξωτερικοί σου δίσκοι είναι σε καλή κατάσταση.

**Ποιοι δεν πρέπει να ασχοληθούν:** Άτομα που χρησιμοποιούν αποκλειστικά εμπορικές streaming υπηρεσίες και δεν ενδιαφέρονται να επιμεληθούν τη δική τους βιβλιοθήκη media. Αν είσαι ευχαριστημένος με Netflix, Disney+, κ.λπ., και δεν έχεις ψηφιακά αντίγραφα media, αυτό το project δεν είναι για σένα.
